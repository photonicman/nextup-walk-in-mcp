# Security policy

## Reporting a vulnerability

Please report security issues privately to **security@nextupwalkin.com**. Don't open a public
issue. Include the steps to reproduce, what you expected and what happened.

We acknowledge reports within three business days and keep you updated until the issue is
resolved. Please give us a reasonable time to fix an issue before you disclose it publicly.

NextUp Walk-in's full security policy and contact details:

- https://nextupwalkin.com/security
- https://nextupwalkin.com/.well-known/security.txt

## Scope

This covers the hosted MCP server at `https://app.nextupwalkin.com/mcp`. The server is
read-only and needs no credentials. It returns only information that businesses already show
customers on their public NextUp Walk-in pages.
